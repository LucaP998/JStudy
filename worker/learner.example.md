so Claude can adapt the questions. `learner.md` is not tracked by git. Delete the examples
below that don't apply. Your recent mistakes are added automatically; use this file for
things that last longer.

- Native language: English. Studying for the JLPT (level and date).
- Background: e.g. "studied with a textbook for two years, a few minutes of Anki every day".

- Weak areas: e.g. "onomatopoeia that look alike (ぐったり / ぎっしり / ぐっすり), so in vocabulary
  about a quarter of the questions should be mimetic words from the whole range of the level,
  with confusable words as distractors".
